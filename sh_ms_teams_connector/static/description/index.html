Odoo Microsoft Teams Connector

This module allows you to schedule and manage Microsoft Teams meetings directly from the Odoo Calendar. When a calendar event is created in Odoo, a Microsoft Teams meeting link is automatically generated and synchronized with Microsoft Outlook Calendar, and any updates or deletions made in Odoo are reflected in Teams to keep all participants informed. The module supports both automatic synchronization and manual control, giving users full flexibility in managing meetings, and also allows users to join Teams meetings directly from the Odoo event view.

Features

Seamless Odoo-Teams Connector

Provides a smooth and reliable connection between Odoo and Microsoft Teams, enabling uninterrupted communication between both platforms.

Teams Meeting Link Generation

Creates a Microsoft Teams meeting link directly from an Odoo calendar event.

Automatic Synchronization Settings

Allows users to enable or disable automatic meeting creation, updates, and deletion.

Manual Meeting Management

Provides manual buttons to create, sync, or delete Microsoft Teams meetings from Odoo.

Meeting Creation Synchronization

Ensures that Microsoft Teams meetings are created and synchronized immediately when a calendar event is created in Odoo.

Timezone Accuracy Management

Maintains correct meeting times across different user time zones.

Microsoft Calendar Event ID Storage

Shows the Store Microsoft Calendar event IDs to maintain synchronization and event tracking across systems.

Teams Sync Error Log Storage

Shows the Capture and store Microsoft Teams synchronization error messages for troubleshooting and audit purposes.

Meeting Delete Synchronization

Deletes the related Microsoft Teams meeting when the Odoo calendar meeting is removed.

Direct Meeting Access

Enables users to join Microsoft Teams meetings directly from the Odoo calendar event.

Recurring Event Synchronization

Supports synchronization of recurring calendar events with Microsoft Teams.

Participant Invitation Handling

Automatically sends meeting invitations to attendees added in the Odoo event.

Meeting Change Synchronization

Updates meeting details in Microsoft Teams when event information is modified in Odoo.

Connection Status Visibility

Displays whether a user's Microsoft account is connected or not.

Meeting Sync Status Indicators

Shows the current state of meeting synchronization, such as pending, synced, or error.

PKCE-Based OAuth Authentication

Shows the Enhance security using PKCE-based OAuth authentication for secure user authorization and token exchange.

Click the Settings icon to access the system configuration menu.


Enter your Azure App credentials (Tenant ID, Client ID, Client Secret) in the Microsoft Teams Calendar Integration settings to authorize the connection.


Copy the Application (client) ID and Directory (tenant) ID from the App Overview page to use in your Odoo configuration.


Navigate to Certificates & secrets and click + New client secret to generate the security key needed for Odoo.


Enter a description for the secret and click Add to generate the new security key.


Copy the generated Value immediately, as it is displayed only once and is required to complete the Odoo configuration.


Paste the Azure credentials into the Odoo configuration fields and click Save to finalize the integration setup.


Click your profile avatar in the top right and select Preferences to access your personal user settings.


Copy the Redirect Url from the Microsoft Teams tab, as this specific address must be added to your Azure App's Authentication settings.


On the Azure App Overview page, click Add a Redirect URI to configure the authentication callback address.


Select Web from the side panel to configure the application for standard web server authentication.


Paste the Odoo callback URL into the Redirect URI field and click Configure to register the authorized return address.


Verify that the specific Redirect URI is now successfully listed under the Web platform section to confirm the configuration is active.


Add the required Microsoft Graph permissions (Calendars.ReadWrite, OnlineMeetings.ReadWrite, User.Read) in the API permissions section.


Click the Connect With Teams button in the User Preferences to log in and link your Microsoft account.


Verify the 'Connected' status and enable Auto Create, Update, and Delete to automate synchronization between Odoo and Teams.


Open the Calendar app and click the New button to schedule a meeting and test the integration.


Click the Create Teams Meeting button on the event form to manually generate a conference link and track the sync status.


Use the Sync with Teams and Delete Teams Meetings buttons to manage the connection manually once the status shows as Synced.


Check your Microsoft Teams calendar to confirm that the Odoo event has successfully appeared at the scheduled time.


Enable the Recurrent option to schedule repeating events and click Sync with Teams to update the full series on both platforms.


Check the Microsoft Teams calendar to confirm that the recurring event series (e.g., every Monday at 13:00) has been successfully synchronized.
